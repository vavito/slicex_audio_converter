RESPONSABILIDADE DE CADA CAMADA
-------------------------------

presentation
------------
Responsável por:
- Endpoints REST
- Receber requisições HTTP
- Upload/download de arquivos
- DTOs
- Tratamento de erros HTTP

application
-----------
Responsável por:
- Casos de uso
- Orquestração das regras
- Fluxo da aplicação

domain
------
Responsável por:
- Regras de negócio
- Contratos/interfaces
- Entidades
- Enum de formatos suportados

infrastructure
--------------
Responsável por:
- Implementações externas
- Integração com FFmpeg
- Acesso ao sistema operacional
- ProcessBuilder

config
------
Responsável por:
- Beans
- Configurações gerais
- Variáveis externas


CONVERSÃO DE ÁUDIO
------------------
Inicialmente:
- WAV -> MP3
- MP3 -> WAV

Ferramenta:
- FFmpeg


ENDPOINT INICIAL
----------------

POST /api/audio/conversions

Recebe:
- multipart file
- formato destino

Retorna:
- arquivo convertido


EXEMPLO DE FLUXO
----------------
Controller
    ↓
UseCase
    ↓
AudioConverter (interface do domínio)
    ↓
FfmpegAudioConverter (implementação)
    ↓
FFmpeg


OBJETIVO DO MVP
----------------
- Upload de áudio
- Conversão entre WAV e MP3
- Download do arquivo convertido
- Estrutura limpa e escalável
